HUMPTY DUMPTY MARDAN — MOBILE POS V1

This is a mobile-friendly Progressive Web App (PWA).
Features: billing, manual barcode entry, Bluetooth/USB keyboard-style scanner support, camera barcode detection where the browser supports BarcodeDetector, products/stock, size/color, discount, payment methods, sales report, backup and print dialog.

To install on Android:
1. Put these files on a web host using HTTPS (or open from a local development server).
2. Open index.html/site in Chrome.
3. Use browser menu -> Add to Home screen / Install app.

Important: local data stays on that phone/browser. Windows↔Android automatic sync is not included in V1; that requires an online database and login, planned for V2.
